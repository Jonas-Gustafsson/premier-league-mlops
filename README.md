# ⚽ Premier League MLOps

An end-to-end Data Engineering and MLOps project for predicting Premier League match outcomes.

## 🏗️ Architecture

Football API → Python → PostgreSQL → Machine Learning → MLflow → FastAPI

## 🛠️ Tech Stack

- Python
- PostgreSQL
- MLflow
- FastAPI
- Docker
- Raspberry Pi

## 📊 Data

Match data is retrieved from [football-data.org](https://www.football-data.org/) using their REST API.

Raw API data is stored locally for development and is **not included in this repository**.
